محتوى الموقع، في مكان واحد.

ارفع الصور وجهّز التعديلات أولًا. النشر لكل الزوار يحتاج اتصالًا بحساب GitHub المالك للموقع.

إعداد الاتصال لأول مرة
  1. من إعدادات حساب GitHub، افتح Developer settings ثم Personal access tokens ثم Fine-grained tokens.
  2. اختر مستودع shapex فقط وصلاحية Repository permissions → Contents → Read and write، وحدد مدة صلاحية مناسبة.
  3. انسخ المفتاح والصقه هنا. لا ترسله في محادثة أو تنشره في ملفات الموقع.
